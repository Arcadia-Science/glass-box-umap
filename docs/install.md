## Using pip

glass-box-umap is hosted on the [Python Package Index (PyPI)](https://pypi.org/project/glass-box-umap/) and can be installed with pip.

```{eval-rst}
.. tabs::

   .. tab:: **Linux**

      .. code-block:: bash

         pip install glass-box-umap

   .. tab:: **MacOS**

      .. code-block:: bash

         pip install glass-box-umap

   .. tab:: **Windows**

      .. code-block:: bash

         pip install glass-box-umap
```
